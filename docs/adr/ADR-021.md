# ADR-021: ObjectStoragePort triển khai S3-compatible — MinIO là ứng viên hiện tại (candidate, chưa đóng băng)

- **Status**: Accepted
- **Context**: Quyết định cam kết ở tầng kiến trúc là abstraction `ObjectStoragePort` phía sau một triển khai S3-compatible, không hard-lock sản phẩm (doc 04 §4.15.1); PostgreSQL lưu object key và metadata, nội dung file nằm trong object store (doc 03 §3.12, ADR-012). MinIO là ứng viên hiện tại, nhưng kho `minio/minio` đã archive/read-only từ 2026-04-25 (issue minio/minio#21584) và Community Edition là bản source-only với mức bảo trì giảm — vì vậy trước khi pin image chính thức, bắt buộc chạy ADR so sánh implementation (doc 04 §4.15.2). Đã chạy spike `backend/scripts/validate_s3_compat.py` trên MinIO `RELEASE.2025-09-07T16-13-09Z` (image date-tagged đang pin trong docker-compose): toàn bộ bề mặt `ObjectStoragePort` (PUT, GET round-trip byte-identical, DELETE, LIST, presigned GET, tồn tại 6 bucket theo doc 03 §3.12.1) PASS 11/11, kết quả ghi tại `docs/evaluation/s3-storage-validation.md`. Đã so sánh các implementation thay thế (SeaweedFS Apache-2.0, Garage AGPLv3, Ceph RGW LGPL-2.1/3.0, managed S3 ngoài scope do chạy local) theo tiêu chí doc 04 §4.15.2: image Docker ổn định, giấy phép phù hợp khóa luận, tính năng bucket/versioning/ILM/WORM, RAM trên máy 19 GB, độ tin cậy bảo trì 2026.
- **Decision**: Adopt **MinIO** làm triển khai S3-compatible **ứng viên hiện tại** cho `ObjectStoragePort`, swappable ở tầng config (`MINIO_ENDPOINT`/`MINIO_ACCESS_KEY`/`MINIO_SECRET_KEY`/`MINIO_BUCKETS`/`MINIO_USE_SSL`, alias `S3_*` theo doc 07 §7.3.3). Quyết định này **explicitly KHÔNG bất khả nghịch**: alternatives đã được ghi nhận trong `docs/evaluation/s3-storage-validation.md` §5 (fallback chính: SeaweedFS), và việc xác minh bắt buộc qua `backend/scripts/validate_s3_compat.py` trước mỗi lần pin/bump image hoặc đổi endpoint.
- **Consequences**: (1) Pin image date-tagged đã test (`minio/minio:RELEASE.2025-09-07T16-13-09Z`), cấm floating tags (`latest`/`alpine`/`main`) theo doc 07 §7.3.3; bump image phải chạy lại `validate_s3_compat.py` trước khi promote. (2) Backup là **replication (async) hoặc `mc mirror`/`mc cp` sang nơi lưu trữ độc lập** — tiering/ILM/transition KHÔNG phải backup (doc 03 §3.12.3, doc 04 §4.15.4). (3) Đường swap implementation đã định nghĩa: đổi config endpoint, chạy `validate_s3_compat.py` + storage tests, promote; không đổi tầng ứng dụng nhờ `ObjectStoragePort`. (4) Chấp nhận GNU AGPLv3 cho server MinIO standalone không sửa đổi; nếu sau này AGPL/copyleft hoặc trạng thái archive trở thành blocker, chuyển sang SeaweedFS (Apache-2.0) theo cùng đường swap. (5) MinIO là candidate, không ghi "MinIO = selected" như quyết định hoàn tất; ADR này có thể bị thay thế khi có quyết định đóng băng sau này.
- **Date**: 2026-08-14
