# ADR-012: MinIO làm object storage

- **Status**: Accepted (**amended by immutable snapshot/provenance and minimal feedback scope, 2026-09-10**).
- **Context**: Cần lưu PDF nguồn, parser output, ảnh trang và artifact ingestion/evaluation cùng metadata truy vết. MVP không có review approval; provenance phải đủ để tái lập và xác minh từng câu trả lời.
- **Decision**: Object storage (MinIO/S3-compatible implementation) lưu source PDFs, parser output, page images và ingestion/evaluation artifacts; PostgreSQL lưu object key, immutable snapshot ID, content hash, source URL, retrieval timestamp, parser/config/embedding metadata và gate outcomes. Mỗi promoted snapshot/artifact được content-addressed hoặc hash-pinned; không sửa tại chỗ, và thay đổi tạo snapshot mới. Buckets riêng theo loại artifact. Backup bằng server-side replication hoặc `mc mirror`/`mc cp` sang nơi lưu trữ độc lập; tiering/ILM không phải backup. Feedback chỉ lưu anonymous `LIKE`/`DISLIKE` tối thiểu, không lưu comment/raw prompt-answer/PII, và không phải release gate.
- **Consequences**: Thêm một service hạ tầng; dữ liệu file tách khỏi database, cần đồng bộ metadata khi restore. Provenance storage tăng nhẹ nhưng cho phép kiểm tra citation và rollback snapshot.
- **Date**: 2026-07-19; amendment 2026-09-10.
