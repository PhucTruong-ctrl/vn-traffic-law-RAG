# ADR-011: Background ingestion qua Redis + Dramatiq, không parse đồng bộ

- **Status**: Accepted (**amended; MVP ingestion is allowlist-only/manual CLI, 2026-09-10**).
- **Context**: Parse PDF trong request handler chặn request và khó kiểm soát tài nguyên. MVP chạy single-user trên localhost/private network, không có auth/admin/reviewer role/API/UI; nguồn duy nhất là các local PDF thuộc allowlist exact `datafiles.chinhphu.vn`.
- **Decision**: Ingestion chỉ chạy background hoặc manual CLI, không có upload endpoint, admin API, reviewer approval hoặc human gate. CLI nhận file local và metadata nguồn đã allowlist; phải kiểm tra exact allowlist, document/hash deduplication và bất biến snapshot trước khi parse. Pipeline: parse -> normalize -> extract -> resolve_refs -> resolve_temporal -> quality_gate -> provenance_gate -> embed -> index. Gate fail giữ artifact/status để audit nhưng không đưa vào serving corpus. Nếu giữ Redis/Dramatiq cho background execution, worker vẫn single-worker và idempotent; đây là implementation detail, không mở rộng product surface.
- **Consequences**: MVP không có upload API/job-status contract; ingestion không thể nhận nguồn ngoài allowlist. Background/CLI giữ request path nhẹ khi có worker, còn manual CLI cho phép vận hành riêng tư và tái lập.
- **Date**: 2026-07-19; amendment 2026-09-10.
