# ADR-016: LangGraph là controlled workflow, không phải autonomous agent

- **Status**: Accepted (**amended by the closed workflow and ingestion-time source sync decision, 2026-09-10**).
- **Context**: Cần orchestration có nhánh và retry nhưng không cần planning tự do. MVP tách ingestion-time source synchronization khỏi query-time serving để truy vấn không phụ thuộc web.
- **Decision**: LangGraph điều phối đồ thị xác định: START -> analyze_query -> resolve_temporal -> expand_query -> retrieve_parallel -> fuse -> rerank -> expand_legal_context -> check_evidence -> build_context -> generate -> verify -> finalize/repair/abstain -> END. Repair có giới hạn bằng counter trong state. Không gọi hệ thống là agent và không cho phép tool planning/network fetch trong query workflow. Ingestion-time source sync là workflow riêng, closed và deterministic: exact allowlist validation -> fetch -> hash/deduplicate -> parse -> normalize -> extract -> resolve_refs -> resolve_temporal -> quality/provenance gates -> embed -> rebuild/promote; gate fail không được promote. Không có human approval step.
- **Consequences**: Hành vi query tiên đoán được, dễ test từng node và không có open-web leakage; ingestion có thể cập nhật snapshot mà không thay đổi query graph đang phục vụ.
- **Date**: 2026-07-19; amendment 2026-09-10.
